HOSTS
=====

One gate, one adapter per host. The core (src/) never learns which host it runs under;
each adapter turns the host's turn-end event into a Turn, runs the gate, and turns the
outcome back into the host's own answer. `orly hosts` prints this table from
adapters/hosts.ts; `orly install <host>` writes what the host needs.

Three tiers, decided by what the host's hook API can do:

  blocks the stop   the host has a stop hook that takes a reason and keeps the agent working
  re-prompts        the host cannot refuse a stop, so the adapter prompts it again with the reason
  orly judge        no hook can keep the agent working; call `orly judge` from your own loop


HOW EACH ONE IS INSTALLED
-------------------------

Plugin ecosystems (the manifests are checked in, so the host's own installer works):

  Claude Code       claude plugin marketplace add yesitsfebreeze/orly
                    claude plugin install orly@orly
                    hooks/hooks.json wires Stop, SessionStart and PreToolUse; /orly:orly
  Codex CLI         codex plugin marketplace add yesitsfebreeze/orly, then `orly install codex`
                    the plugin ships the $orly skill; hooks go in .codex/hooks.json
  Gemini CLI        gemini extensions install https://github.com/yesitsfebreeze/orly
                    then `orly install gemini`: the extension ships /orly, the hooks go in settings.json
  Copilot CLI       copilot plugin install yesitsfebreeze/orly, then `orly install copilot`
                    the plugin ships the skill; hooks go in .github/hooks/orly.json
  Cursor            /add-plugin from this repository for the skill, then `orly install cursor`
  Factory Droid     droid plugin marketplace add https://github.com/yesitsfebreeze/orly
                    (Droid reads .claude-plugin and hooks/hooks.json); or `orly install droid`
  Qwen Code         qwen extensions install yesitsfebreeze/orly; or `orly install qwen`
  Pi                pi install git:github.com/yesitsfebreeze/orly (package.json's pi field)
  Goose             `orly install goose` writes an Open Plugins bundle under .agents/plugins/orly/
  OpenCode, Kilo    `orly install opencode|kilo` writes a one-line plugin shim

Everything else: `git clone https://github.com/yesitsfebreeze/orly && bun orly/bin/orly.ts install <host>`.
`--global` writes the user-level file instead of the project's; `--dry-run` shows the
files first. The command is idempotent and leaves other hooks in the same file alone.

`bun install -g github:yesitsfebreeze/orly` puts `orly` on PATH.


WHAT EACH ADAPTER ANSWERS
-------------------------

  adapters/claude-code.ts   Claude Code's hook dialect, dispatched on hook_event_name.
                            Stop -> {decision: "block", reason}; SessionStart -> additionalContext;
                            PreToolUse -> permissionDecision deny. Also Droid, Qwen, Continue,
                            Junie and Antigravity, which speak the same dialect.
  adapters/codex.ts         Same dialect; the transcript is a rollout JSONL under
                            ~/.codex/sessions and transcript_path may be null, so it is found by id.
  adapters/gemini.ts        AfterAgent -> {decision: "deny", reason} (the reason is sent back as a
                            new prompt); SessionStart; BeforeTool for write_file and replace.
  adapters/cursor.ts        stop -> {followup_message}: Cursor submits it as the next user message.
                            No pre-edit hook; the Stop-time baseline is the guard.
  adapters/copilot.ts       agentStop -> {decision: "block", reason}; camelCase and PascalCase
                            fields both read. Copilot ends the turn after 8 consecutive blocks.
  adapters/goose.ts         Stop -> {decision: "block", reason}. No transcript in the payload: the
                            turn is rebuilt from `goose session export --id`.
  adapters/opencode.ts      A plugin: on session.idle it reads the session's messages through the
                            SDK client, and on a block prompts the session again with the reason.
                            tool.execute.before throws to refuse a weakening edit.
  adapters/pi.ts            An extension: agent_end judges event.messages; a block becomes a
                            follow-up user message. tool_call refuses a weakening write or edit.
  adapters/transcripts.ts   Reads any transcript on disk: Claude JSONL, Codex rollouts, Gemini and
                            Qwen chat files, Copilot event logs, plain {role, content} logs.
  adapters/opencode-export.ts  `opencode export $ID | bun adapters/opencode-export.ts | orly judge`
  adapters/hosts.ts         The table behind `orly hosts` and `orly install`.


THE ECHOED REASON
-----------------

Most hosts deliver a block reason as the next user prompt, so it ends up in the transcript
as if the human had typed it. normalizeLastTurn skips messages that begin the way orly's
reasons begin and keeps the work before them in the turn, so a second judgment sees the
whole turn and the original request. Claude Code marks them isMeta; the others do not.


WHAT IS VERIFIED
----------------

The transcript readers, the fail-open paths of every adapter, and the installer are
exercised by `bun test` against payloads shaped like each host's documentation. Claude Code
is the host this repository was built in. Droid, Qwen, Continue, Junie, Kilo and the
plugin-ecosystem install commands are wired from documentation and not yet run against the
host; `orly hosts` marks them.
A hook that fails, on any host, lets the agent stop: a judge that is down never becomes a
wall.


NOT GATED
---------

  Windsurf     post_cascade_response fires after the answer and cannot block or continue it
  Cline        TaskComplete can only cancel the task, not send it back
  Kiro         the Stop payload carries no message and no transcript, and cannot block
  Amp          the plugin API is experimental; use `orly judge` from the terminal
  Aider        no hooks

For these, pipe the turn into `orly judge` (exit 0 = may stop, 2 = not done) from
whatever loop drives the agent, or run `orly ask` between turns.
