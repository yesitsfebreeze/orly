THE GUARD
=========

The agent that tunes the gate is the one the gate judges. Left alone, the cheapest way to
pass is to lower a cut. So weakening is refused by the harness, not discouraged in prose.


WHAT COUNTS AS WEAKENING
------------------------

  - lowering a cut
  - deleting a spec
  - marking a spec optional
  - dropping an explicit cut that was above the default
  - rewording a spec while keeping its fitted cut (refit it, or drop the cut)
  - deleting a check or context source, or replacing its command with one that cannot
    fail (true, exit 0, a bare echo)
  - clipping a source's maxChars shorter

Tightening a cut, adding a spec or check, and rewording with a refit are always allowed.


WHERE IT IS ENFORCED
--------------------

PreToolUse: an Edit or Write to a spec file or the goal is replayed against the whole
spec tree before it happens, and denied if the result is weaker.

Stop: shell edits never reach PreToolUse, so every judgment also compares the specs and
checks with the strictest set seen (.orly/baseline.json). A weakened gate blocks the turn.
The baseline only advances when nothing was weakened.


LIMIT
-----

A spec reworded into something vacuous, with its cut raised, passes both. The gate makes
weakening visible and awkward; owning the specs stays with you.
